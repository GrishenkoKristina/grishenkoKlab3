# Хранители древних реликвий

Браузерный 2D-платформер на HTML, CSS и обычном JavaScript с Canvas. Визуальная концепция основана на присланных референсах: средневековые костюмы и доспехи, геральдические знамёна, старинный камень, металлическая отделка и магические предметы.

## Запуск
1. Распакуйте архив.
2. Откройте папку `artifact_platformer` в Visual Studio Code.
3. Запустите `index.html` через расширение Live Server. Также можно открыть файл напрямую в современном браузере.

## Управление
- `A` / `D` или стрелки влево / вправо — движение.
- `Space`, `W` или стрелка вверх — прыжок.
- На телефоне доступны экранные кнопки.
- Кнопки «Пауза» и «Заново» находятся под игровым полем.

## Цель
Собрать три реликвии — кристалл, солнечную печать и лунный камень — затем добраться до древних врат. Падение в огненную бездну приводит к поражению. Лучший результат сохраняется в `localStorage`.

## Технологии
HTML5, CSS3, Canvas API, JavaScript ES-модули. Игровой цикл построен на `requestAnimationFrame`, физика зависит от `dt`. Сторонние игровые движки и сборщики не используются.

## Нейросеть и промпты
При разработке использовалась ChatGPT. Примеры запросов:
- «Создай платформер на Canvas с физикой движения, прыжком и столкновениями с платформами».
- «Разработай визуальный стиль средневекового фэнтези: каменная крепость, геральдические знамёна, рыцарь и магические реликвии».
- «Добавь сбор трёх предметов, условие победы, опасную зону, паузу, рестарт и сохранение рекорда».

Графика персонажа, окружения и предметов отрисовывается средствами Canvas, внешние изображения не используются.


## Запуск игры двойным нажатием

Для простого запуска откройте файл `index.html` двойным щелчком мыши. В этой версии игровой JavaScript собран в `game.bundle.js`, поэтому браузеру не нужно загружать ES-модули через `file://`.

Также можно запускать проект через Live Server в VS Code. Для публикации на GitHub Pages загрузите все файлы этой папки в корень репозитория.
